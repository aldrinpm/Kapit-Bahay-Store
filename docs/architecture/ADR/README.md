# Architecture Decision Records

Store one decision per Markdown file, for example `0001-state-management.md`.

Use this template:

```markdown
# ADR-0001: Decision title

- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD

## Context
What problem or decision is being addressed?

## Decision
What did we decide?

## Alternatives considered
What reasonable options were evaluated?

## Consequences
What are the trade-offs and follow-up actions?
```
