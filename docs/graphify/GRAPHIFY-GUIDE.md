# Graphify Guide

Repository: https://github.com/Graphify-Labs/graphify

Use Graphify to analyze relationships in the source code and documentation when it is installed and configured.

Important:
- Read the current official repository documentation before installation or execution.
- Do not assume Graphify is an Obsidian plugin.
- Do not invent CLI commands, config files, flags, or automation hooks.
- Keep generated graph artifacts separate from authoritative requirements.
- Refresh graph output after meaningful structural changes, according to the tool's documented workflow.
- Review graph findings; do not blindly treat inferred relationships as correct.

Expected value:
- Explore code dependencies.
- Understand component and module relationships.
- Navigate documentation and implementation connections.
- Support impact analysis during refactoring.
