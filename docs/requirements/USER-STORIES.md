# User Stories

## Storefront and discovery
- As a customer, I want to understand what the store sells as soon as I land on the page.
- As a customer, I want to browse product categories so I can find relevant items quickly.
- As a customer, I want to search by product name so I can locate a specific item.
- As a customer, I want to sort products by price and popularity.
- As a customer, I want to see featured and discounted products.
- As a customer, I want to see a useful empty state when no products match.

## Product details
- As a customer, I want to view product details before adding an item.
- As a customer, I want to choose a quantity.
- As a customer, I want to know whether a product is in stock.
- As a customer, I should not be able to add more units than available stock.

## Cart
- As a customer, I want to add products to my cart.
- As a customer, I want to change item quantities.
- As a customer, I want to remove products.
- As a customer, I want to see line subtotals and the cart total.
- As a customer, I want my cart to remain available after refreshing the page.
- As a customer, I want an empty-cart state with a way to continue shopping.

## Checkout
- As a customer, I want to enter my name, mobile number, and delivery address.
- As a customer, I want to review my order before submitting.
- As a customer, I want to select simulated Cash on Delivery.
- As a customer, I want to receive an order reference and confirmation after submitting.
- As a customer, I want the interface to make clear that the order is simulated and no real transaction occurs.
